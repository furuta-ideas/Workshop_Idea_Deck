# v0.8 バックグラウンド同期と画面改善

## Notion同期

操作はサーバーへ即時保存し、操作が10秒止まるとNotion送信を開始します。送信中もマインドマップの追加・直接編集・移動・削除を続けられます。送信完了を待つ全体ロックを外しました。

送信対象は世代番号付きの固定スナップショットとして専用KVへ永続保存します。Notionへ送る処理の途中経過はそのスナップショットへ記録し、作業中のボードは書き換えません。完了時は物理ブロックIDと同期結果だけを現在のボードへ反映します。送信中に増えた変更は次の送信に残します。通信失敗・応答消失・プロセス再起動でも、保存した送信対象と操作ジャーナルから回復します。

Notion読取り中に新しい編集が発生した場合、その読取り結果を捨て、保存済みの編集を保持します。Notionも別途変更されていた場合は競合として管理者が解決します。本文同期障害中も作業を保存できます。再試行とNotion側の明示的な採用は歯車の管理者設定へ移しました。

権限確認は本文送受信と分けて更新します。実際の参加者権限の失効・期限超過・権限情報の陳腐化は引き続き拒否します。同じトピックを複数人が同時編集したときのrevisionによる競合検査も維持します。

同期状態だけの変化ではマインドマップを再描画しません。変更のない各ノードでワークショップ全体を保存する処理も削減しました。

## 空欄トピック

新規トピックの空欄確定時に一時IDが選択状態に残り、Enter/Insertから実在しない親を持つ編集状態が作られていました。空欄確定は取消として扱い、元の選択へ戻します。空欄から続けて新しい編集欄を開かず、存在しないトピックに対する編集開始も拒否します。Enter・Insert・フォーカス移動・Esc後の選択と直接編集を検証しています。

## 画面

- ①②③④のタブをブランドと同じ最上段へ移動。右側はメール・歯車・ビルド情報を表示し、アカウントアバター・パスキー登録・ログアウトのボタンを削除。
- 同期の通常メッセージ領域はマップ上部から削除。詳細・再試行・再読込みは管理者設定のNotion連携へ配置。
- 左メニューはアイコンで縮小・展開。状態はブラウザー内へ保存。縮小時もチームの切替が可能。
- ログイン入口・認証入力・メインへ、同じビルド時刻を`yyyy/mm/dd hh:mm:ss`（日本時間）で表示。`scripts/stamp-build.js`がビルド時に生成し、Cloudflareビルドは自動実行。アクセスした現在時刻ではありません。
- AIアドバイス欄には実際に接続したサービスとモデルを表示。未接続時は「外部AI未接続：md基本ガイドを表示（生成AIモデルは未使用）」と表示。

Genspark Enterpriseという既定の選択値だけでは接続しません。接続と認可が未設定の現在は、md内の基本ガイドを使い、外部生成AIへ送信しません。

## 検証

95件の自動テストが成功。分離したCloudflareネイティブWorkerで実際のDurable Objectアラームを途中停止し、同時のHTTP編集が25msで200を返し、完了後も新しい編集が残ることを確認しました。これは偽データ・偽通信による実行基盤の試験であり、本番Notionへの書込み速度を測った値ではありません。

再現用：`node node_modules/wrangler/bin/wrangler.js dev --config test-support/wrangler-background.jsonc --local --port 4341 --persist-to .wrangler/background-proof`で分離環境を起動し、別端末から`node scripts/check-background-worker.js`を実行します。設定・データは本番から分離され、検証用エンドポイントは本番Workerに含まれません。
