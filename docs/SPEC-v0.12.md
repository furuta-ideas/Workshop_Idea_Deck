# v0.12 ドラッグ・投票の修正と企画生成

マップはPointer Eventsで操作します。上下のすき間にも挿入線を出し、枝と子孫をまとめて並べ替えます。Alt＋↑／↓は廃止。投票部品や展開ボタンからはドラッグを始めず、ドラッグ後のクリックも抑制します。操作中のポーリングによる再描画を防ぎます。

①②のカード投票は自分のチームの編集者もアイコンから開始・終了できます。④の全体投票は管理者が開始します。＋で１票、投じた人だけに−を表示し、予算と時間、閲覧・他班の制限をAPIでも確認します。

③の絞込み済みカードと配置済みカードも同じPointer Eventsで動かします。落とした枠の位置を保持し、既存カードを別枠に落とすと入れ替えます。デッキは最大５枚で、枠配置もNotion②のJSONへ同期します。従来のコンパクトなデッキ記録も読み込めます。Notionでdeckだけを編集した場合は、そのリストを優先して配置を再構成します。

右側の説明パネルを削除し、録音開始を「ディスカッションの記録」横へ配置します。別途の議論開始操作は不要です。企画項目は一言で言うと、Who、What、How、３つの特長（各１行・200字）、模擬プレスリリースの順です。既存の重要論点・キーワード・ラウンド履歴は保存して保持します。

模擬プレスリリースは約400字の新聞記事を生成し、レビューして適用します。可視化はオレンジのボタンから16:9の企画提案シートを生成し、レビューして適用します。生成前に未保存のフォームを保存し、現在の企画・カード・議論を渡します。生成の重複実行を抑止します。企画の一言・３つの特長・原稿はNotion③とMarkdownにも記録します。

AIは利用者の指定によりGenspark経由に限定します。画像モデルは`gpt-image-2.5`。管理者設定に文章用・画像用のプロンプトを別々に用意し、初期値は依頼内容を整理したものを使います。Genspark公式GSK APIへ接続できる秘密入力欄を追加しました。登録時に`/api/tool_cli/me`で確認し、キーを画面・設定API・監査ログへ返しません。公式GSK CLI 1.15.3の公開仕様に従い、文章モデルとプロキシURLは`opencode-config`から取得します。Genspark以外のAIへ直接送信・自動切替しません。

実環境の保存済みGenspark資格情報は読み取り確認でHTTP401でした。新しいキーは管理者設定で登録する必要があります。モックAPIで各経路・秘密保護・生成結果のレビュー／適用を検証しましたが、実アカウントの生成・モデル利用権・クレジット消費を伴う試験は未完了です。

全132自動テストに加え、通常プロフィールと分けたヘッドレスEdgeで実マウス相当のドラッグ・クリック・キー入力を実施しました。自チームの編集者で上下移動、Alt廃止、①②投票・取消、指定した空き枠への配置、新しい文章項目の保存を確認しています。本番のトピック・票・議論は試験用に変更していません。
