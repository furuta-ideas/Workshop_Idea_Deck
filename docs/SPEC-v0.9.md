# v0.9 MindManager互換コピー・貼り付けとNotion自動登録

## コピー・貼り付け

①で貼り付け先を選択してCtrl＋Vを押すと、コピーしたアウトラインを子トピックとして一括追加します。「貼り付け」ボタンでは、テキストを貼り付けて「子として追加」「同じ階層に追加」を選べます。選択がない場合は中心トピックの下へ追加します。

MindManagerのプレーンテキスト形式を使います。TABとスペースによる字下げを読み取り、親子関係・同じ階層・並び順を保ちます。添付のサンプルはShift-JISのテキストファイルで、実際の字下げは半角スペース2文字でした。8トピック・4階層をそのまま復元します。クリップボード上の文字はUnicodeとして扱います。

選択したトピックでCtrl＋C、または「コピー」を押すと、そのトピックと全子孫をTAB＋CRLFのアウトラインへ変換します。折り畳み状態でも全子孫を含みます。中心を選択したコピーは中心名と全枝を含みます。これはテキストの階層互換であり、MindManagerのバイナリ形式`.mmap`や装飾・画像・独自メタデータの読込みではありません。MindManager側での実アプリへの貼付け確認は未実施です。

文字入力中は通常の文字のコピー・貼り付けとして扱います。閲覧者・他班表示では貼り付けられません。選択した場所の色を引き継ぎ、1回の操作・revisionで保存します。文字数超過、不正な字下げ、貼り付け後500項目を超える入力は全体を拒否し、部分追加しません。同じ操作IDの再送は重複追加しません。

貼り付け内容もサーバーへ即時保存し、10秒の操作停止後にNotionへバックグラウンド同期します。

## 新規ワークショップ

Notion接続済みで「ワークショップを作成」すると、設定済みのWS一覧データソースから、名前が一致する「ワークショップテンプレート」を検索し、そのIDを明示してページを作成します。名前・終了日・状態はフォーム値を設定し、テンプレートの日時変数はAsia/Tokyoで解決します。指定テンプレートがない・同名が複数・共有不足の場合は作成を止めます。

ページIDをサーバーへ保存してから、Notionの非同期テンプレート展開を次の定期同期で確認します。待機中は準備中と表示し、新しいWSの編集を止めます。既存WSのマップ編集には影響しません。①〜④の見出しと参加者一覧DBが現れるまでは子DBを新規作成しません。

`参加者一覧 (1)`のようなNotionの複製名にも対応します。DBが新しいWSの配下に独立して複製されたことを検証してから、作成者を参加者へ追加し、テンプレートのチームと本文を取り込みます。各チームの中心名は新しいWSのテーマとし、②③④の対応表も初回送信で新しいIDに更新します。テンプレート元のページやDBは変更しません。

作成ボタンの二重送信を防ぎ、同じ操作IDは既存の作成結果を返します。ページ作成要求後の通信結果が不明な場合は、ローカルの作成記録を保持して確認待ちとし、外部作成を自動再送しません。管理者がNotion一覧と照合する従来の復旧手順を使います。

実装は[Notion公式のテンプレート作成仕様](https://developers.notion.com/guides/data-apis/creating-pages-from-templates)と[テンプレート一覧API](https://developers.notion.com/reference/list-data-source-templates)に従っています。

## 検証

添付サンプル、TAB混在、空行、複数ルート、文字数・件数・権限・再送、通常入力との区別、折り畳んだ枝のコピー、Notionトグルへの同期と再読込みを自動試験しています。WS作成は指定テンプレートID、展開待ち、DB重複防止、同名テンプレート拒否、独立DB検証、作成結果不明時の再送停止を偽通信で検証しています。

実Notionはテンプレート名・IDと構造の読取りを確認しています。この変更の検証では本番に試験WSを追加していません。
