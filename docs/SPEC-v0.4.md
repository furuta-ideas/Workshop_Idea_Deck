# 更新仕様 v0.4

2026-11-03の追加依頼を反映。v0.3と異なる点は本書を優先します。

## ログイン・画面

- 提供されたオープニング画像を無加工で5秒表示し、必ずログイン入口へ進みます。既存セッションが有効でも入口を省略しません。「本人確認してログイン」から既存セッションを再検証し、未ログイン時はメールOTP・パスキー画面へ進みます。
- 大きなWORKSHOP／STEP見出しを削除し、4タブを本文の最上部へ配置。Tour PlayBookの参考画像に合わせて緑・青・金・テラコッタのグラデーションにします。
- BIZ UDPGothicを同梱配信します。外部フォントサービスへブラウザーから通信しません。[Google Fonts公式配布](https://github.com/google/fonts/tree/main/ofl/bizudpgothic)のRegular／Boldを使用し、`public/fonts/OFL.txt`にSIL Open Font Licenseを同梱します。

## マインドマップ

- クリーム色のキャンバス、曲線、藍色の中心・第1階層、赤色の第2階層、コーラルの第3階層、灰色の深い階層。グループ色は小さな丸印と②のカード色で確認できます。
- 入力フォームからの追加は親選択なし。右側の単独エリアの末尾へ追加します。
- トピックをダブルクリックすると、その場で直接編集できます。文字に合わせて横幅を調整。Enterで保存後に同階層の入力、Insertで保存後に子の入力へ進みます。選択中のトピックでもEnter／Insertで追加を開始。F2で編集、Escapeで入力を取り消します。日本語変換確定中はショートカットを実行しません。
- 中心トピックからの追加はメイントピックとして扱います。中心の直接編集はチーム固有の表題で、NotionのWSテーマを変更しません。
- ドラッグで移動元の枝と子孫を別のトピックや中心へ接続。右の単独エリアへ落とすと枝ごと切離し。「単独に」は直下の子も別の単独トピックにします。循環する接続はサーバーで拒否します。
- 「接続先を選ぶ」ボタンからクリックでも接続できます。削除は確認画面を経由し、子の枝を単独として残します。該当項目のカード投票・デッキ選択を解除します。
- ＋／−で折り畳み・展開。折り畳み時は全子孫の件数を表示します。全折り畳み・全展開、拡大・縮小、横・縦スクロールを用意。折り畳み状態は閲覧端末内の状態で、共有データを変更しません。
- 旧マップの親なし項目は初回起動時に中心への接続へ移行し、既存の見え方・文字・IDを保存します。移行後の新規項目は単独になります。
- 操作の参考：[MindManager公式ユーザーガイド](https://onlinehelp.mindjet.com/help/MindManager/18/EN/documents/MindManager_User_Guide.pdf)。Enter＝同階層、Insert＝子は利用者の確認済み仕様です。

## チームの閲覧と音声入力

- 同じWS内の全TEAMSを選択でき、マップ・デッキ・議論を閲覧できます。メンバー一覧と個人別投票は従来の制限を継続。
- 管理者を含め、ボードの変更とAI処理は割当チームだけです。管理者のWS・参加者・投票時間等の管理は継続します。他チームのカード投票も不可。④の全チーム画像への投票は従来どおり可能です。
- 気づき入力欄にマイクを配置。認可済み文字起こし接続がある場合だけ録音します。停止後は編集可能な文字起こしプレビューを表示し、入力欄へ追記してから明示保存します。画面移動時は録音を破棄してトラックを停止。ブラウザー標準のSpeechRecognitionや外部サービスへの代替送信は行いません。

## mdファシリテータ

- 初版は利用者添付の`AI_facilitator_behavior_spec.md`を解釈。原文を`docs/AI_facilitator_behavior_spec.md`、実行用の初期値を`config/ai-facilitator.md`に収録します。
- 初回起動時に`DATA_DIR/ai-facilitator.md`へコピー。以後は管理者設定のMarkdown欄で編集・保存・ダウンロードします。サーバー更新で管理者の編集を上書きしません。版のハッシュで同時編集を検出して409を返します。
- 先頭の`facilitator-config` JSONは、基本ガイド、介入間隔、回数制限などの機械設定。本文はAIが読む振る舞い仕様です。認可済みAIへは毎回、保存済みmd全体と対象チーム・現在フェーズを送ります。メンバーのメールや個人の投票内容は入力に含めません。
- 各画面にロボットと吹き出し。「閉じる」「あとで」「ミュート」「助言をもらう」「考えを入力する」を用意。基本ガイドは「md基本ガイド」と明示し、AI応答を装いません。
- 自動介入は既定90秒以上、フェーズ導入を除き最大4回。入力・ドラッグ・別の吹き出し表示中・投票中は抑制。空白が2分、停滞が3分などの場合に短い問いを提示。120文字上限、同一フェーズの同じID・同文を再表示しません。自動吹き出しは6〜12秒、手動助言は閉じるまで表示します。
- 分類提案はプレビューで確認した場合だけ適用し、色を変更します。未分類項目は残し、直後の分類を元に戻せます。分類後に色の変更がある場合は上書きを防いで取り消しを拒否します。
- アニメーションは状態表示に限定し、動きを減らす設定を尊重します。読み上げは追加していません。
- 現在の環境はAI未接続です。動的な深掘り・自動分類・音声認識は、社内認可済みGatewayの正式接続後に実サービスで確認します。md基本ガイドと編集機能は接続なしで利用できます。

添付仕様の将来拡張（複数キャラクター、読み上げ、新聞画像等）を一括実装済みとは扱いません。従来依頼で指定された赤い合計票表示は維持し、AIには票の内訳・結果を与えません。
