# 公開用Nodeサーバー

このアプリはNode.js 24、永続ローカルディスク、GmailへのSMTP接続を使います。静的ファイルだけの公開では、OTP認証とNotion同期は動作しません。公開先は未指定で、公開URLはまだ発行していません。

## 配置するもの

`Dockerfile`で通常アプリのコンテナを構築できます。`.dockerignore`は必要なソースのみを許可し、`.env`、SQLite、実データ、監査ログ、Gitメタデータをビルドへ送信しません。既存のコンテナ実行環境へ、1インスタンスで配置してください。

```sh
docker build -t workshop-idea-deck .
```

この作業環境にはDockerがないため、コンテナのビルド・起動は未検証です。配置先が決まった後に実行して確認します。

## 公開先の設定

| 項目           | 設定                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| 接続           | 外部HTTPSからコンテナのHTTPポートへ転送                                                                    |
| 待受け         | `HOST=0.0.0.0`、`PORT=4317`（サービス指定ポートにも対応）                                                  |
| オリジン       | `APP_ORIGIN=https://公開ホスト名`（末尾スラッシュなし）                                                    |
| パスキー       | `RP_ID=公開ホスト名`（スキーム・ポートなし）                                                               |
| Cookie         | `SECURE_COOKIE=true`                                                                                       |
| ディスク       | 永続ローカルボリュームを`/app/data`へマウントし、コンテナのnodeユーザーに書込み権限を付与                  |
| プロセス数     | 1。複数レプリカ・共有ネットワークディスクで同一SQLiteを開かない                                            |
| ヘルスチェック | `GET /api/health`                                                                                          |
| Gmail          | `SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURE`、`SMTP_USER`、`SMTP_PASSWORD`、`SMTP_FROM`を公開先の秘密設定へ登録 |
| Notion         | `NOTION_TOKEN`、`NOTION_WORKSHOPS_SOURCE`、必要なら`NOTION_POLL_SECONDS`を公開先へ登録                     |

Gmail SMTPへの外向きTCP接続を許可する環境が必要です。アプリパスワードとNotionトークンはチャット・Git・イメージへ含めず、公開先の秘密設定へ渡します。

新規ディスクではNotionからワークショップ・権限・マップ・記録を取り込みます。既存の利用者パスワード・個人票・管理者が編集したAI用md等も引き継ぐ場合は、ローカルの通常サーバーを停止して整合バックアップを取り、安全な経路で永続ディスクへ移します。ログインセッションとパスキーは公開URLに合わせて再ログイン・再登録を行います。ローカルと公開先を同時に編集用として運用しないでください。

## 公開後の確認

発行されたHTTPS URLで起動し、通常モード・OTP設定有効・Notion同期完了を確認します。実利用者のメールでログインし、①のチーム別トグルとマップ、②③④の記録を読み返します。検証用の追加・削除は、利用者が指定したテストデータの範囲で行います。
