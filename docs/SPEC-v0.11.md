# v0.11 上下移動・マップ投票・絞込みカード・カジノデッキ

## 上下移動

トピックをドラッグし、相手の上端・下端へ落とすと挿入線の位置へ枝全体を移します。中央へ落とすと従来どおり子トピックへ接続します。選択後の↑↓ボタン、Alt＋↑／↓でも兄弟の順番を変えられます。子孫・ID・色・票・デッキ選択を保ち、Ctrl＋Zで取り消せます。自分の枝の中への移動や他班の変更は拒否します。

順序も10秒待機後のNotion背景同期へ含めます。既存トグルの単なる文字更新では順序が変わらなかったため、順序を保って残せる枝を選び、動かす必要のある枝を所定位置へ複製して旧ブロックを整理します。子孫の多い枝をなるべく残し、処理量を抑えます。論理IDは変えず、応答消失後の再試行も既存のジャーナルで重複を防ぎます。

## ①と②の投票

[Miro公式の投票ガイド](https://help.miro.com/hc/en-us/articles/360017572274-Voting)の、投票アイコンからセッションを開始し、オブジェクトの＋／−で投票・取消する操作を参考にしました。Miroへの接続は行いません。

開始・締切は従来どおり管理者が担当します。①の投票アイコンでカード投票を開始すると、参加者の自分のチームのトピックへ＋が表示されます。自分が1票以上投じた項目だけに−が表示されます。クリックごとに1票追加・取消し、複数投票・持ち票・時間制限・閲覧権限を既存APIで検証します。終了時は投票ボタンを隠します。説明文は置かず、アイコン、ボタン、数値、アクセス用ラベルとツールチップを使います。

①と②は同じ`cards`投票を使用します。別の投票箱は作りません。票の変化だけならマップ全体は再描画せず、投票部品だけを更新します。投票中は部品の幅を確保し、＋の位置とスクロール位置を安定させます。

## ②のカード

合計1票以上のカードだけを表示します。自分の投票だけを取り消す−と、追加投票の＋を使い、「あなたの投票」の文章は削除します。全員の票が0になったカードは一覧から外れます。

右上のソートアイコンは、得票数の多い順とマップの順番を切り替えます。同票はマップ順です。表示上のソートなので、マップやNotionの階層順を変更しません。

## ③のデッキ

確認回答に従い、緑のカジノテーブルと、③タブと同系統のゴールドの枠・見出しを組み合わせました。5つの角丸枠へカードを置き、空き枠も常に表示します。「得票したカード」は「絞込み済みカード」へ変更し、デッキの下段へ配置します。下段からのドラッグ追加、枠間の移動、除去は継続します。狭い画面ではテーブルを横スクロールできます。

## 検証

枝の前後移動・子孫保持・取消・循環と権限拒否、Notionでの兄弟順と再読込み、追加応答消失後の回復を試験しました。DOMでは投票開始・追加・自分だけの取消・締切・①②の共有・得票フィルター・ソート・マップDOMとスクロールの保持・5枠と上下段構成を検証しています。分離した偽データの画面をヘッドレスEdgeで描画し、マップ投票と緑／ゴールドのデッキ配置も確認しました。本番のトピックや票を検証用には変更していません。
