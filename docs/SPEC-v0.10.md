# v0.10 枝の削除とマップ操作の取り消し

①のトピック削除は確認ダイアログを出さずに実行します。Deleteキーとトピック操作メニューから削除でき、選んだトピックと全子孫を一括削除します。関連するカード票・Notion取込み票・デッキ選択も同じ処理で取り除きます。中心トピックはマップの土台として残します。

Ctrl＋Zまたはツールバーの「元に戻す」で、自分が行ったマップ操作を最大20回まで取り消せます。追加、直接編集、色、中心名、移動、単独化、階層貼付け、枝の削除、承認後のAI分類・マップ用音声追加が対象です。入力欄で文字を編集中のCtrl＋Zは、ブラウザー標準の文字の取り消しを使います。投票・議論・タイマー・表示倍率・折り畳み状態はマップの履歴には含みません。

履歴は利用者・WS・チームごとにサーバーへ保存し、画面更新後も使えます。画像を含むWS全体のコピーは保存せず、変更したノード・元の順序・削除時の関連情報だけを保存します。履歴全体の上限は2MiBで、大きい一括操作の場合は20回より少なくなります。履歴を参加者向けのWS応答へ含めません。

他の参加者やNotion側がマップを変更した場合は、過去の全体へ巻き戻して変更を消さないよう、取り消しを拒否します。その後の自分の新しいマップ操作から改めて履歴を記録します。他チームや閲覧者による取り消しは拒否します。削除を取り消す際は関連票とデッキも復元しますが、削除後の新しい投票・選択によって上限を超える場合は全体を変更せず、調整を案内します。

Notion同期による物理ブロックID変更は取り消しの競合に含めません。現在のIDを維持し、既に削除済みの枝を戻す場合は、同じ論理ID・文字・階層を新しいNotionブロックへ再作成します。同期中の取り消しもサーバーへすぐ保存し、世代番号付きの次の背景送信で反映します。10秒待機中に削除を取り消した場合、Notionへ削除を送信しません。

自動検証では、親・子・孫の削除と一括復元、20回上限、連続した各種操作の取消、同じ操作IDの再送保護、他者更新・閲覧権限・票数競合時の保護、Notion送信中の取消と復元を確認しています。検証は偽データとテスト用通信で行い、本番のトピックを削除していません。
